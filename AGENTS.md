# AGENTS.md

This repository is an Unraid AIO application package for vanilla GBrain.

## Repository intent

- Treat this repo as the source of truth for the `gbrain-aio` runtime wrapper.
- Keep the app repo focused on the Dockerfile, rootfs, XML, tests, and app documentation.
- Keep shared validation, release, registry, upstream, and catalog policy in `aio-fleet`.

## Engineering expectations

- Preserve the security invariants in `tests/test_dockerfile_policy.py` and the centralized `aio-fleet` security policy.
- Keep the upstream GBrain commit pinned and verified in the Dockerfile.
- Keep the XML `<Changes>` block in the date-first fleet format generated by `aio-fleet`.
- Respect protected branches and PR-based automation.

## Release model

- This repo publishes a Docker image and a Community Applications XML.
- Formal changelog updates and GitHub Releases are release-driven.
- Keep changelog-friendly Conventional Commit titles and PR titles.

## Community expectations

- Support `awesome-unraid` catalog sync.
- Keep CA-ready metadata accurate: `Project`, `Support`, `TemplateURL`, `Icon`, `Overview`, `Category`.
- Document tradeoffs plainly, including Postgres, TLS, and Ollama dependencies.
